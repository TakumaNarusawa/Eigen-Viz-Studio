# Eigen-Viz Studio

固有値・固有ベクトルの極上可視化Webアプリケーション。
ブラウザ上で動作する数学エンジン（Pyodide & SymPy）を利用し、2D平面や3D空間における線形変換を視覚的に理解するための教育・可視化ツールです。

## 主な機能

- **2D 平面変換**: 2x2行列による空間の変形と、向きが変わらないベクトル（固有ベクトル）の可視化。
- **3D 空間変換**: 3x3行列による3次元空間の変形、回転・伸縮軸の可視化。
- **動的計算エンジン**: ブラウザ内で動作する Python (SymPy) を用いて、入力された行列の固有値や固有空間をリアルタイムに解析。

## 技術スタック

- HTML5 Canvas & CSS3 (モダンなガラスモフィズムUI)
- [Three.js](https://threejs.org/) (3D空間描画用)
- [Pyodide](https://pyodide.org/) & [SymPy](https://www.sympy.org/) (ブラウザ内での高度な数式処理)
- [KaTeX](https://katex.org/) (数式レンダリング)

## 使い方

1. ローカル環境でWebサーバーを起動します（例: Pythonの組み込みサーバーなど）。
   ```bash
   python -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000/` にアクセスします。
3. 画面上のコントロールパネルから変換行列を入力するか、プリセットを選択して変換を実行してください。
