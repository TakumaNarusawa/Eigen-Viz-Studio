# Eigen-Viz Studio
> **固有値・固有ベクトルの極上可視化Webアプリケーション**

Eigen-Viz Studio は、線形代数学における最重要概念の一つである「線形変換」「固有値」「固有ベクトル」を、ブラウザ上で直感的かつ美しく可視化する教育・研究用Webアプリケーションです。

ブラウザ内で動作する高精度な数学エンジン（**Pyodide & SymPy**）と、美しい 3D WebGL グラフィックス（**Three.js**）を融合させ、紙の上だけでは理解しづらい「空間の変形」と「固有空間」の関係性を極上のビジュアルで表現します。

- **デモサイトURL**: [Eigen-Viz Studio デモサイト](https://eigen-viz-studio.takumanarusawa.workers.dev/)
- **開発言語・環境**: HTML5 / JavaScript (Vanilla) / CSS3 (ガラスモフィズムUI) / Cloudflare Pages

## 🌌 本アプリケーションの数学的アプローチ

線形代数学において、正方行列 $\mathbf{A}$ によるベクトル $\vec{x}$ の写像 $\mathbf{A}\vec{x}$ は、「空間を引っ張ったり、回転させたり、潰したりする変形操作」と捉えることができます。

### 1. 固有値と固有ベクトル（幾何学的定義）
通常、空間を変形させるとほとんどのベクトルの「向き」は変わってしまいます。しかし、変形前後で**「向きが変わらず、長さの伸縮（実数倍）だけが起こる特別なベクトル」**が存在します。これが **固有ベクトル (Eigenvector)** であり、その伸縮率が **固有値 (Eigenvalue) $\lambda$** です。

$$\mathbf{A}\vec{v} = \lambda\vec{v}$$

- **2D平面における可視化**: 空間グリッドの変形アニメーションと共に、ブレない直線をなす固有空間（シアン色の光の軸）がダイナミックに輝きます。
- **3D空間における可視化**: 3x3行列による空間全体の伸縮や回転変形に対し、回転の不変軸や伸縮方向をエメラルドグリーンの光の軸として立体的に可視化します。

### 2. 複素固有値と不変楕円の軌道
行列によっては、実数の範囲に固有ベクトルが存在しない場合があります（例：回転行列）。その場合、空間の固有ベクトルは「複素数（虚数）」の領域に隠れてしまいます。

本アプリでは、2Dモードにおいて実固有ベクトルが存在しない（固有値が複素共役のペア $\lambda, \bar{\lambda}$ となる）場合、**不変空間（不変楕円の軌道）**を自動計算して可視化します。
複素固有ベクトル $\vec{v} = \vec{u} + i\vec{w}$ （$\vec{u}$ は実部、$\vec{w}$ は虚部）が張る平面は、線形変換において空間がぐるぐると回転・伸縮する軌道を示しており、本アプリはその美しい楕円軌道（マゼンタ色の光）を計算し可視化することで、虚数の世界が実数平面に及ぼす幾何学的影響を視覚的に提示します。

### 3. 行列の対角化（Diagonalization）の 3 ステップ理解
対角化可能な行列 $\mathbf{A}$ に対し、固有ベクトルからなる基底変換行列 $\mathbf{P}$ と対角行列 $\mathbf{D}$ を用いた表現：

$$\mathbf{A} = \mathbf{P}\mathbf{D}\mathbf{P}^{-1}$$

を、本アプリは独自の**マルチステージ・幾何学アニメーション**によって視覚的に説明します。

1. **Step 1: 基底変換 $\mathbf{P}^{-1}$** - 固有ベクトルを新しい座標軸とする「固有空間（基底）」へと世界を回転・歪ませます。
2. **Step 2: 伸縮 $\mathbf{D}$** - 新しい座標軸に沿って、それぞれの固有値 $\lambda_i$ 倍だけ純粋に直交伸縮させます（せん断や回転のない、最もシンプルな伸縮）。
3. **Step 3: 元の空間への射影 $\mathbf{P}$** - 伸縮された世界を、元の座標系へと引き戻します。

この一連の動きにより、複雑な行列変換 $\mathbf{A}$ が、本質的には「固有空間で引き伸ばしてから戻すだけ」の極めてシンプルな操作であるという本質を幾何学的に体験できます。

## 🛠️ 技術スタック & 設計のこだわり

### 1. ブラウザ完結型の Python 計算エンジン (Pyodide & SymPy)
サーバーサイドでの重い数式計算を完全に排除し、**WebAssembly** 上で Python 実行環境を動かす **Pyodide** と、強力な数式処理ライブラリ **SymPy** をブラウザ内で駆動させています。
- 入力された任意の行列成分から、固有方程式を代数的に解き、厳密な固有値・固有ベクトルを瞬時に算出します。
- 数式レンダリングには高速な **KaTeX** を使用し、計算結果を美しい数式表示（重解表示や特異行列の解説付き）でレンダリングします。
- 計算プロセスの暴走を防ぐため、**WebWorker** を採用。メインのUIスレッドと計算スレッドを完全に分離し、最大3〜5秒のタイムアウト検知と自動復帰ロジック（スレッド再生成）を実装した堅牢な非同期処理を行っています。

### 2. WebGL & HTML5 Canvas による超美麗アニメーション
- **3D ビューポート**: WebGL ラッパーである **Three.js** を用いて実装。滑らかな軌道追従カメラ（OrbitControls）により、直感的に視点を回転・ズームして 3 次元変換の様子を全方位から観察できます。
- **2D ビューポート**: 高速な HTML5 2D Canvas により、高周波のグリッド線描画と補間イージングアニメーションを 60FPS で軽快に処理します。

### 3. ハーモニアス・ダークネオン & グラスモフィズム UI
- デザインシステムには、深みのある漆黒の背景にサイバーパンク調のシアン、エメラルド、マゼンタ、パープルのネオングローを配した「極上のダークテーマ」を採用。
- 半透明 of the ガラス効果（`backdrop-filter` による飽和度向上を伴う Glassmorphism）を多用し、コントロールパネルや計算結果 HUD がグラフィックスの上に浮かび上がるような極めてプレミアムな立体感と質感を醸し出しています。

### 4. モバイル対応 (Responsive & Dynamic Fluid Resize)
- タブレットやスマートフォンでの表示にも完全に対応。メディアクエリにより画面比率に応じてコントロールパネルとビューポートの配置を最適化。
- ウィンドウサイズやタブ切り替えイベントを検知し、WebGL レンダラーや 2D Canvas の解像度を動的に再計算して追従させるため、アスペクト比が崩れることなく常にくっきりとした高解像度の表示を維持します。

### 5. 高いセキュリティ＆クリーンなコード
- ユーザー入力値の数値型への厳格なバリデーション（`parseFloat` + `isFinite`）と、エラー処理部における `textContent` や安全な DOM 生成による徹底的な XSS 対策。
- 外部 CDN の固定バージョン（信頼のおける jsDelivr, unpkg）の利用による依存関係の安全化。

## 🚀 ローカルでの動作手順

本アプリケーションは完全にブラウザ側で完結する静的アセット構成となっています。セキュリティ上の制約（WebWorkerの読み込み制限など）のため、ローカルで動作確認を行う際は、ローカル Web サーバーの起動が必要です。

### 1. リポジトリのクローン
```bash
git clone https://github.com/あなたのユーザー名/Eigen-Viz-Studio.git
cd Eigen-Viz-Studio
```

### 2. ローカルサーバーの起動

#### Python の場合 (簡単)
```bash
python -m http.server 8000
```

#### Node.js / npm (http-server) の場合
```bash
npx http-server -p 8000
```

### 3. ブラウザでアクセス
ブラウザを開き、以下のアドレスにアクセスしてください。
- [http://localhost:8000](http://localhost:8000)
